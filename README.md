# Figma n8n Connector

This project contains a Figma plugin and an n8n node that allow you to programmatically add images and text to your Figma files from your n8n workflows.

## Figma Plugin

### Installation

1.  Open the Figma desktop app.
2.  Go to the "Plugins" menu and select "Development" > "Import plugin from manifest...".
3.  Select the `manifest.json` file in the `figma-plugin` directory.

### Usage

1.  Open a new Figma file.
2.  Right-click on the canvas and select "Plugins" > "n8n Connector".
3.  Copy the webhook URL from the plugin's UI.

## n8n Node

### Installation

1.  Copy the `n8n-nodes-figma` directory to the `~/.n8n/custom` directory on your n8n server.
2.  Restart your n8n server.

### Usage

1.  Create a new n8n workflow.
2.  Add the "Figma" node.
3.  Paste the webhook URL from the Figma plugin into the "Figma Webhook URL" field.
4.  Fill in the other fields with the data you want to send to Figma.
5.  Run the n8n workflow.

## How it Works

The n8n node sends a POST request to the webhook URL generated by the Figma plugin. The Figma plugin then uses a long-polling mechanism to receive the data from the n8n node and create the image and text objects on the Figma canvas.

##
Note

This is a proof of concept and has some limitations. The long-polling mechanism in the Figma plugin is simulated and should be replaced with a proper implementation that communicates with a backend service.
